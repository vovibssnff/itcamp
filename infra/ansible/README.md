# Ansible — production deploy of KTC on Deckhouse (VK Cloud)

Push-based delivery: Terraform creates N static worker VMs → this collection bootstraps Deckhouse Hybrid, adopts workers via CAPS, then deploys data-layer + apps with Helm.

## Prerequisites

- Control host: `ansible>=2.16`, `docker`, `kubectl`, `helm>=3.14`, `jq`, `yq`
- Filled `inventory/prod/group_vars/all/vars.yml` (domain, registry, email)
- Encrypted vault: `cp inventory/prod/group_vars/all/vault.yml.example inventory/prod/group_vars/all/vault.yml && ansible-vault encrypt ...`
- Inventory: generated by Terraform (`hosts.ini`) or copy `hosts.ini.example`
- SSH key at `~/.ssh/ktc_ed25519`

## Install collections

```bash
cd infra/ansible
ansible-galaxy collection install -r requirements.yml
```

## Run

```bash
# Full pipeline
ansible-playbook site.yml --ask-vault-pass

# By phase
ansible-playbook site.yml --tags os --ask-vault-pass
ansible-playbook site.yml --tags bootstrap --ask-vault-pass
ansible-playbook site.yml --tags nodes,modules,baseline,edge --ask-vault-pass
ansible-playbook site.yml --tags data,migrate,apps,seeds,obs,smoke --ask-vault-pass
```
