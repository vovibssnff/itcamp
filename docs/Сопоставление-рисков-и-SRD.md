# Сопоставление рисков ИБ со средствами защиты из SRD

**Документ-источник мер:** `SRD-Конструктор-КТК.md`, v2.2  
**Методика:** для каждого риска — меры, **явно описанные в SRD**.  
Если SRD закрывает риск — в колонке КАПСОМ стоит **—**.  
Если нет — описать минимально необходимое решение

> **Примечание:** «Администратор» в SRD — роль управления **тренажёрным комплексом**, не IT-инфраструктуры (**FR-ROLE-05**).
