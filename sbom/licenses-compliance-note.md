## 1. Резюме (статус)

**Вывод: лицензионных блокеров нет. Платежей за используемые библиотеки нет.**

- Подавляющее большинство зависимостей — **permissive** (MIT, BSD, Apache-2.0, ISC) —
  использование в закрытом коммерческом продукте допускается свободно (нужно только
  воспроизведение уведомлений).
- **Ни одной «проприетарной/платной» и ни одной GPL/AGPL-лицензии не обнаружено.**
- Требуют внимания/юридического подтверждения — **2 позиции**:
  - `psycopg` / `psycopg-binary` — **LGPLv3** (Python-драйвер Picodata);
  - `caniuse-lite` — **CC-BY-4.0** (данные, требует attribution).
- Остальные «подозрительные» в автоматическом отчёте — **артефакты распознавания**
  (фактически permissive), детали в § 4.

**Деньги:** лицензионных отчислений за библиотеки SBOM **нет и не будет**. В стоимость
продукта разумно заложить только разовые работы по комплаенсу (§ 6).

## 2. Обязательства по категориям лицензий

| Лицензия | Тип | Обязательство | Платёж |
|---|---|---|---|
| MIT, BSD-2/3-Clause, ISC | permissive | включить текст лицензии/copyright (copia) в дистрибутив | нет |
| Apache-2.0 | permissive (с патентами) | copyright notice + указание изменённых файлов | нет |
| **LGPLv3** | слабый copyleft | при динамическом использовании — не нарушать условия LGPL (см. § 3.1) | нет |
| **CC-BY-4.0** | данные (attribution) | указать авторство/источник данных | нет |
| CC-BY-SA-4.0 | share-alike (докс) | касается только документации, не кода | нет |
| GPL / AGPL | сильный copyleft | производный код должен оставаться GPL — **отсутствует** в стеке | нет |

## 3. Позиции, требующие внимания

### 3.1. `py-ai`: psycopg, psycopg-binary (v3.2.3) — **LGPLv3**

- **Что это:** официальный Python-драйвер для PostgreSQL/Picodata (используется для
  связи с БД в `ai`-сервисе).
- **Почему важно:** LGPLv3 — слабая copyleft-лицензия. Она **не запрещает** использовать
  библиотеку в закрытом приложении, если она подключается **динамически** и её код
  не модифицируется.
- **Наш случай:** Python подключает модуль через `import` (динамически), исходники
  драйвера не модифицируются → **использование допустимо** без раскрытия кода сервиса.
- **Рекомендация:** зафиксировать в комплаенс-политике: 1) драйвер не форкается;
  2) обеспечивается возможность замены версии драйвера пользователем (стандартно для pip);
  3) при необходимости — подтверждение юристом. Риск низкий.

### 3.2. `fe-frontend`: caniuse-lite (v1.0.30001807) — **CC-BY-4.0**

- **Что это:** база данных совместимости браузеров (зависимость browserslist/autoprefixer,
  используется при сборке CSS).
- **Почему важно:** это **данные**, лицензия CC-BY-4.0 (Attribution) — требуется
  **указание авторства** базы при распространении.
- **Рекомендация:** включить `caniuse-lite`/`browserslist` в список attribution в
  third-party notices. Кода она не содержит → блокирующей не является.
