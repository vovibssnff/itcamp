Проект: «Конструктор КТК»
Источник: `docs/economic/software-inventory.csv` (машиночитаемый перечень), `docs/architecture/ARCHITECTURE.md`, `docs/SRD-Конструктор-КТК.md`.
Дата: 2026-08-10

---

## Как пользоваться документом

- **CSV** (`software-inventory.csv`) — полный перечень из **59 позиций** ПО с колонками:
  `категория | ПО | роль | лицензия | тип_затрат | требуется_расчёт_в_деньгах | примечание`.
- Данный MD — сгруппированный справочник с акцентами на **денежные** статьи.
- **14 позиций** требуют расчёта в деньгах (лицензии/подписки/поддержка/оборудование),
  остальные — **open source (бесплатно)**, в себестоимость идут только трудозатраты.

## 2. Бесплатное ПО (open source) — только трудозатраты

### Языки и рантаймы
Go (BSD), Python 3 (PSF), Node.js 22 (MIT), pnpm (MIT).

### Бэкенд-библиотеки (Go): MIT/BSD/Apache — бесплатно
pgx/v5, go-redis/v9, nats.go, minio-go, go-ldap v3 + stdlib.

### Бэкенд-библиотеки (Python): MIT/BSD/Apache — бесплатно
FastAPI, uvicorn, grpcio, protobuf, prometheus-client, numpy, pydantic и др.
> Единственный нюанс: **psycopg (LGPLv3)** — не деньги, а юридические обязательства
> (см. `sbom/licenses-compliance-note.md`).

### Фронтенд: MIT/Apache/ISC — бесплатно
React 18, react-router, zustand, konva, antd, uplot, i18next, openapi-fetch;
инструменты: Vite, TypeScript, ESLint, Prettier, Vitest, Playwright, msw и др.

### Промежуточный слой — бесплатно
NATS JetStream (Apache-2.0), Istio (Apache-2.0), Fluent Bit (Apache-2.0).

### Инструменты CI/CD и разработки — бесплатно (кроме Enterprise)
Docker, Helm, golangci-lint, ruff, mypy, Syft, go test, Playwright.
> GitLab CI / Gitea Actions: CE — бесплатно; Enterprise — платная (уточнить).

## 4. Ключевые тезисы для экономиста

1. **Платных лицензий, которые обязательно закладывать:** Deckhouse, VK Cloud (инфра),
   Picodata+Radix, Пульт+Графиня, KUMA, антивирус, PAM, GPU, StarVault, Angie (поддержка),
   при необходимости GitLab Enterprise / MinIO enterprise.
2. **Основная масса ПО (языки, все библиотеки, брокер, mesh, мониторинг-агенты) —
   бесплатная** (open source permissive). В себестоимости отражаются как **трудозатраты**,
   а не лицензионные отчисления.
3. **Единственный комплаенс-риск среди библиотек — LGPLv3 у `psycopg`**: не денежная
   статья, но требует юридического подтверждения (подготовлено в лицензионном паспорте).
4. **Весомые непрерывные затраты** — вычислительные ресурсы (VK Cloud) и GPU для ИИ.
